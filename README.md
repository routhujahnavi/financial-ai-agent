# 📈 Financial AI Agent

AI-powered Indian Stock Market Research Platform

## 🌐 Live Demo
https://financial-ai-agent-roan.vercel.app

## Features
- 🤖 AI stock analysis using Groq LLM
- 📊 30-day price charts
- 💼 Portfolio tracker with live P&L
- 🔴 Live Indian stock data

## Tech Stack
- Frontend: Next.js, Tailwind CSS, Recharts
- Backend: FastAPI, Python
- AI: Groq (llama-3.3-70b)
- Data: yfinance
